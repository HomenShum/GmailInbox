# Agent Instructions

This repo is a public-safe distribution of a private Gmail workspace. Treat privacy as part of correctness.

## Minimal Inbox Redesign

When asked to simplify, reimagine, or redesign the workspace UI/UX, read:

```text
.claude/skills/minimal-inbox-redesign/SKILL.md
docs/agent-methods/minimal-inbox-redesign.md
```

Use the method to:

1. Inspect the current UI or screenshot.
2. Identify the user's immediate decision.
3. Research comparable interaction patterns.
4. Collapse the workflow into `Now / Prep / Batch / Later`.
5. Produce a public-safe demo artifact.
6. Verify the artifact in-browser.
7. Run a privacy scan before publishing.

## Privacy Rules

Do not commit raw Gmail, LinkedIn, calendar, resume, OAuth, or local machine artifacts.

Prefer synthetic demo data, anonymized labels, public-safe images, and reproducible scripts.
